Roles

QA

  • Pre Release. Verify there is a version in JIRA associated with all stories in release. Make sure the version description and release date are accurate
  • Pre Release. Create Jira task for the release, add it to the appropriate sprint, and link to the wiki release checklist
  • Pre Release. Create and send release Outlook meeting invite to release team
  • Release. Ensure all automated tests are passing, (unit, integration, UI where applicable)
  • Release. Smoke Test after notification received
  • Release. Notify team of successful release by replying all to Outlook calendar invitation
  • Post Release. Do a Gitk to verify branch merging
  • Post Release. Close the release task, verify checklist is complete and close the version, making sure the release date is accurate

SD

  • Release. Ensure no Batch Jobs are running
  • Release. Make a copy of production
  • Release. Push code to production
  • Release. Notify team that we are ready for smoke test
  • Release. Smoke Test after notification received
  • Post Release. Pull the release branch
  • Post Release. Pull the master branch
  • Post Release. Merge release branch into master
  • Post Release. Push to master
  • Post Release. Merge master to any open release branches
  • Post Release. Create Release Tag on Master Branch
  • Post Release. Delete release branch if applicable
  • Post Release. Delete backup of production
  • Post Release. Notify team to GRPO and delete/re-pull Integration branches

BA

  • Release. Smoke Test after notification received
