Jira release checklist

This file lists every conditional rule. It is not a flat todo list.
Do only the items whose conditions match the answers.
Never turn off, unplug, or disable smoke alarms or carbon monoxide alarms.
On the checklist page, follow only the Applicable items section
(#applicable-checklist-text). Tasks that do not apply are omitted there.

Questions:
1. Is this your first release for this program?
   Default answer: No
2. Will this release impact the availability scripts?
   Default answer: No
3. Does this release include any new batch jobs?
   Default answer: No
4. Does this release include any change to a Rule Engine?
   Default answer: No
5. Does this release require a planned downtime window?
   Default answer: No

Tasks:
1. Always show.
   Section: Pre Release
   Role: QA
   Verify there is a version in JIRA associated with all stories in release. Make sure the version description and release date are accurate

2. Always show.
   Section: Pre Release
   Role: QA
   Create Jira task for the release, add it to the appropriate sprint, and link to the wiki release checklist

3. Always show.
   Section: Pre Release
   Role: QA
   Create and send release Outlook meeting invite to release team

4. Show if any of these answers are Yes: 1. Is this your first release for this program?
   Section: Pre Release

   Section: Pre Release
   Role: QA

6. Show if any of these answers are Yes: 3. Does this release include any new batch jobs?
   Section: Pre Release

   Section: Release
