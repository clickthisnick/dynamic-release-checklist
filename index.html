Answer the questions on a checklist. The page drops tasks that do not apply and lists the remaining items in plain language.

Run locally

  1. Install Node.js 18 or newer.
  2. From this folder, run node scripts/build.js.
  3. Run node scripts/serve.js 8000.
  4. Open http://127.0.0.1:8000/.
